# Design references

Drop 3–8 reference images here (screenshots of mascots, desktop pets, chat panels, motion stills) and add one line per file in `captions.md`:

```
01-bird.png — liked: round silhouette, big eyes. Not liked: too glossy.
02-panel.png — liked: calm chat panel spacing.
```

Agents analyze these in step 2 and write `docs/design/ANALYSIS.md`: shape language, proportions, palette mood, motion feel, panel layout, and what to avoid. The analysis extracts principles; it never copies or traces an existing character, logo or brand.
