# ADR 0006: Windows offline wake and live hypotheses

The user requested button-free activation, a separate “Hey Kiwi” followed by a command, an animated speaker replacing the smile, and live words under the desktop mascot. The previous RMS/MediaRecorder path could only transcribe after a completed recording and required a setting change. It did not meet that interaction.

Use the installed Windows System.Speech recognizer through a small C# helper in a separate process. The demo machine has the MS-2057-80-DESK en-GB recognizer. A constrained “hey kiwi” grammar arms a 12-second dictation window. Addressed commands also work in one utterance. Streaming hypotheses drive captions; audio level updates drive the speaker indicator. Prefix word confidence gates provisional wakes. Only a recognized addressed/follow-up utterance is handed to the existing local Whisper executable for final verification, then routed through the existing validated desktop command path. Audio is passed in memory, never saved in ordinary operation.

Recognizer grammar changes use RequestRecognizerUpdate / RecognizerUpdateReached. WAV diagnostics are paced like microphone audio to avoid grammar changes racing file-buffer consumption. Native pipe records use a fixed event name and base64 text/audio fields, with a size cap. No command strings are executed from hypotheses or from recognizer stdout. Pausing/shutdown invalidates pending final verifications; stop also invalidates them so a late result cannot execute after cancellation.

Default wake is on in 0.1.1. A one-time migration changes the earlier button-based default; subsequent explicit wake-off settings remain respected. The visible badge reflects listener startup/armed/error state. Missing English recognition or denied microphone access is a visible error, and manual recording remains available. Normal local features do not send audio to a cloud service.

This is a Windows-specific adapter selected for the user's installed system, not a claim that sherpa-onnx phase-2 criteria are complete. It requires Windows offline English speech components; other OSes report unsupported. Human wake hit rates and long false-trigger measurements remain unverified. Native hypotheses can be inaccurate and are corrected by the final decoder. The exact wake phrase is “Hey Kiwi”; bare “Kiwi” is reserved for the stop command to reduce false activation.
